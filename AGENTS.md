## Hard constraints
- This Codex environment is not macOS.
- Do not run mac-only tooling or scripts (for example: `xcodebuild`, iOS simulator validation scripts, or any script that requires Xcode/simulator runtimes).
- When macOS validation is required, prepare changes and ask the user (or Claude on a Mac) to run the commands and share results.

- Follow project conventions and workflows documented in `CLAUDE.md`.
- If guidance conflicts, this file takes precedence for Codex execution constraints.
