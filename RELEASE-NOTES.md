0.11.0 is a major leap forward in the quality and usability of Swift bindings. Silent API drops, lifetime crashes under real workloads, stringly-typed Swift errors, and protocol proxies that compiled but didn't dispatch are resolved. Async closures, `AsyncSequence`, closure-bearing protocol methods, constrained generics, and `Equatable`/`Hashable` now generate into working C# end-to-end — unlocking new frameworks that previously couldn't be bound and dramatically expanding the callable surface of frameworks that already could.

## Highlights
- **Lifetime crashes resolved** — Several `SafeHandle`/`GCHandle` paths that crashed under real workloads (`DangerousAddRef` missing on `Equals`/setters, refcount underflow on async cancel, a `stackalloc` pointer being wrapped in a `SafeHandle` and freed, and a SwiftUI bridge finalizer deadlock) are all fixed.
- **Async closures and `AsyncSequence`** — `async` generic methods, throwing async closures, and ObjC-bridged async returns (`[URL]?`, `Set<URL>`, `[String: URL]`) no longer crash or fail to bind, and Swift `AsyncSequence` lowers to `IAsyncEnumerable<T>` so `await foreach` just works.
- **Typed Swift errors** — Plain `throws` and `async throws` now surface as `SwiftException<TError>` carrying the original error type, instead of `String(describing:)`-stringified messages.
- **Protocol proxies actually dispatch** — Closure-bearing protocol methods, nested protocols (`ImagePipeline.IDelegate`), `@objc optional` members as default interface methods, and `@available` inheritance all land — closing the large class of "implements compiles, runtime is silently broken" bugs.
- **`Equatable` and `Hashable` correctly lowered** — Swift `Equatable` enums emit real `Equals`/`==`, conditional generic `Equatable` is honored, and explicit `Hashable` conformance gates a real `GetHashCode` so hash-based collections work.
- **Apple `Matter` framework binds end-to-end** — `MatterSupport.MatterAddDeviceRequest` and the wider Matter umbrella now `--objc` bind cleanly (1330 classes / 21 protocols / 541 enums), closing issue #38; `init` and `setupPayload` no longer drop as `UnresolvableType`.
- **Stripe surface area unblocked** — Cross-module class extensions (`STPAPIClientStripePaymentsExtensions`, `StripeAPIStripePaymentsExtensions`) now emit closure params, async-throws, and static methods, exposing Stripe's callback + async API (`CreateToken`/`Source`/`PaymentMethod`, `ConfirmPaymentIntent`, `CreateRadarSession`, `PaymentRequest`) that previously sat behind empty wrapper classes; `NSObjectProtocol`-only `@objc` protocols (`STPAuthenticationContext`, `STPCustomerEphemeralKeyProvider`, `STPIssuingCardEphemeralKeyProvider`) route through a new `NSObject`-rooted proxy; `StripeFinancialConnections`'s nested result types declared inside `extension StripeCore.StripeAPI {}` and labeled enum-case payloads (`case Completed(label: (...))`) round-trip.

## Generator improvements
- **Closure dispatch through `EveryProtocol`** — Throwing, async, property, and closure-returning closure dispatch all land through proxies; dispatchable-closure proxies now admit one closure plus zero-or-more non-closure value-shape params (unblocking completion-handler-plus-primitive protocol methods like Stripe's `STPIssuingCardEphemeralKeyProvider`); the `Optional<Closure>` reabstraction trap that produced a dangling `$sIeg_ytIegr_TR` partial-app context is fixed; `() -> Void` parameters dispatch correctly.
- **Async breadth** — Class-bound generic async methods bridge with defaulted args; ObjC-bridgeable value types flow through async return paths; async container args hoist onto the deferred-release list; the unspecialized generic-async wrapper symbol is now correctly emitted instead of throwing `EntryPointNotFoundException` on first call.
- **`@_cdecl` wrapper discipline** — Structural `@_cdecl` claim discipline extended across Tier A emitters, distinct-selector siblings on generic-extension methods emit their own wrappers, `Optional<value-type>` renders as `UnsafeRawPointer` in protocol-extension wrappers, and `Optional<Class>` rendering / cross-kind symbol dedup is corrected — closing the class of bugs where the C# `LibraryImport` and Swift wrapper disagreed on ABI.
- **Type projection** — Namespace-facade structs lift into real C# `namespace` blocks instead of nested static classes; nested protocols carry the `I` prefix on the inner type; Swift `Set<T>` parameters project as `IReadOnlySet<T>`; `Swift.SwiftArray<T>` stops leaking into `AsyncStream` element types; `_:` argument labels become anonymous parameters instead of `cGFloat`/`value0`/`_`; `Foundation.UUID` is recognised as an `InlineSwiftStruct` in `ConcreteProtocolSpecializationEmitter` so it round-trips as `System.Guid`, with a per-entry `ISwiftObject` eligibility flag that still rejects `System.Guid` from generic indirect-return paths whose allocator is constrained to `T : ISwiftObject` (unblocks GRDB's `Codable`/`FetchableRecord` specializations).
- **Generics** — `some Protocol` lowers with the correct constraint instead of bare `ISwiftObject`; properties on constrained generic extensions (e.g. `VerificationResult<T>.jws`) emit through `ConstrainedExtensionEmitter`; `Forecast<MinuteWeather>`-style per-specialization property accessors stop firing on the open generic type; generic methods with defaulted empty-collection params get the no-argument trim overload; closed-static-factory accessors on generic structs (e.g. WeatherKit `DailyWeatherStatisticsQuery<T>.temperature : DailyWeatherStatisticsQuery<DayTemperatureStatistics>`) skip parent-`T` / PWT threading when the return type closes over a concrete argument.
- **`@available` and `@objc optional`** — Platform availability propagates onto protocol-proxy classes; `@objc optional` protocol members lower to C# default interface methods (with `Task.FromResult` bodies for async DIMs); spurious `[Obsolete]` no longer broadcasts across an entire overload set.
- **Cross-module and namespace handling** — Swift extensions defined on a type owned by a different module now bridge through `SafeHandle` pinning; third-party frozen/trivial structs used as extension receivers go through a dedicated struct-receiver path that symmetrically lowers `SimpleEnum` params, returns, and property setters across the C ABI; cross-module enum payloads get a payload extractor so payload-carrying cases from a foreign module unwrap without crossing the resilience boundary unsafely; nested-type renames apply to dependency modules loaded via `--framework-dependency`; static Swift xcframeworks route to the Swift binding path instead of being misclassified as ObjC-only; cross-module *class*-receiver extensions now emit closure params, async-throws, and static methods through per-method `@_cdecl` Swift trampolines (mirroring the in-module `WrapperEmitter` and struct-receiver path) instead of dropping the entire surface; nested types declared inside `extension Foreign.Type {}` mirror into a partial-class wrapper in the current module so `CurrentModule.ForeignType.Nested` is reachable from both class and struct receivers; additive cross-module `ProtocolConformances` (e.g. `extension UInt8: SomeProtocol`) merge correctly on cross-module re-home, pending-drain, and `RegisterCrossModuleType` so the CSM associated-type filter walks the right conformance edges; `IsModuleInternal`/`IsSpiProtected` gates added symmetrically so `@usableFromInline`-internal and `@_spi` members aren't forwarded into wrapper modules where they're unresolvable.
- **`NSObjectProtocol`-only `@objc` protocols** — `@objc protocol Foo: NSObjectProtocol` previously skipped silently because the plain Swift `EveryProtocol` class can't satisfy `NSObjectProtocol`'s `NSObject` identity surface. A new `EveryObjCProtocol: NSObject` helper in `Swift.Runtime` plus a branch in `EveryProtocolEmitter`/`ProtocolProxyEmitter` routes those conformances through an `NSObject`-rooted proxy; `IsClassBoundProtocol`/`IsNSObjectProtocolOnly` walk the full `_allProtocols` list for transitive routing; receiver reads pull only the 1-word handle from `selfContainer` instead of the full 5-word `ExistentialContainer1`; `ProxyLifetimeTracker` uses `SwiftReleaseTrampoline.Release` instead of direct `Arc.Release` across the finalizer boundary; `NewFromPayload` preserves both class-bound existential wire words so foreign Swift/ObjC implementations round-trip through their own witness table.
- **Codable, enum payloads, existentials** — Non-generic `Codable` structs get a JSON round-trip surface; enum cases with associated values get factory and `TryGet*` extractors instead of just a `CaseTag`; `any Foo` existentials route through `EveryProtocol` instead of collapsing to `object`.
- **`Equatable`/`Hashable`** — Swift `Equatable` enums emit real `Equals`/`==`; conditional `Equatable` on a generic type propagates the constraint into C# so `Equals` only compiles where Swift can dispatch; `SwiftHashable` emission gates on explicit `Hashable` conformance to avoid `GetHashCode` returning `0`.

## Runtime improvements
- **`SafeHandle` / `GCHandle` lifetime** — `IEquatable.Equals` and nullable-struct property setters now bracket `DangerousAddRef`/`Release`; `DeferredSafeHandleRelease` no longer underflows the refcount on async cancellation; the generic enum-payload extractor stops wrapping a `stackalloc` pointer in a `SafeHandle`; escaping-closure trampolines release their `GCHandle` when Swift releases the closure (`ClosureHandle` helper); `_SBClosureCtx` owner-token threaded through NCB and `PExtCB` callbacks.
- **SwiftUI bridge** — Generated bridge sessions get a finalizer; `_Free` no longer deadlocks the finalizer thread by dispatching synchronously to the main queue.
- **Callback marshalling** — `Array<TStruct>` async args serialize element values instead of `SwiftArray<IntPtr>`; callback closure args use the fully-mapped C# type (e.g. `byte[]`) instead of `Swift.Foundation.Data`; Swift `@_cdecl` wrapper payload buffers are deinitialized and freed; the `async` `Task`-returning overload of a callback method frees the existential payload buffer its callback-style sibling already owned; `MethodClosureBridge`'s complex-enum closure-arg buffer takes ownership in the no-dispose path — MCB Swift wrappers heap-allocate without a `defer` (transferring ownership to C#) but the C# callback emitter previously fell through to `MarshalBorrowedFromSwift` and left nobody to run `VWT.Destroy` + `NativeMemory.Free`, now in parity with the direct `ClosureEmitter` owning marshal.
- **Trimming / NativeAOT** — Protocol availability proxies are preserved through NativeAOT trimming instead of being stripped; cdecl P/Invoke wrappers reached only via reflection survive trimming through targeted `DynamicDependency` roots; simulator and device runtime baselines ratcheted as fixes landed (device gate now 2106 pass / 38 skip).

## Bug fixes
- **Apple-platform interop** — `CoreGraphics.CGImage?` projects as managed `CGImage` (with `CFRetain`/`CFRelease` semantics) instead of `System.IntPtr?`; bridged-`NSArray` async returns stop leaking one retain per call by matching `passRetained` to an owning `ArrayFromHandle` overload; `DataLoader.Validate(NSUrlResponse)` no longer reads its indirect-result buffer before the PInvoke writes to it.
- **Generator emission** — `@available` collisions on overloaded `printedName`s resolved with a `SwiftInterfaceParser` schema v2 bump; overloads that lower to the same C# signature get disambiguation instead of both being silently dropped; container-element overload keys recursively encode generic parameters and tuple elements so `int[]` / `long[]` / `Array<String>` siblings no longer collide on the ObjC-bridge container path; tombstoned-but-visible members replace silent omission for unmarshalable-closure surfaces; Swift methods that collide with `System.Object` virtuals are suffixed; `Foundation.Dimension`-constrained generics emit with a class-bound constraint instead of being marked unsupported.
- **`@_cdecl` symbols** — Mangled Swift symbols stamped with `CallConvCdecl` are eliminated; the in-band wrapper-symbol contract is enforced on direct `DllImport` paths so a `MissingWrapperSymbol` no longer ships as a working-looking PInvoke; `Sett*_vtable` setters now actually export through the proxy vtable.
- **Late 0.11.0 regression sweep** — Kingfisher's C#-protocol-conformance extensions on foreign types are now treated as unreachable post-hoc instead of crashing emission; TipKit's `Array<Optional<Class>>` and `Array<Class>` overloads survive nullability erasure without colliding; Stripe and CryptoSwift no longer emit duplicate wrapper classes when cross-module extension receivers flow through `NonFrozenStructHandler` with `IsFrozen=false`; SkeletonView's `FrozenStruct` property getters are rejected in `ForeignTypeExtensionEmitter` so a generated void-returning getter body no longer leaks past CS0161; StripeApplePay's nested-rename targets walk the renamed type's own nested children so an existing inner type doesn't collide silently (CS0542); FirebaseAuth/Kingfisher's `EveryProtocolEmitter` async modifier now gates on `_useObjCBase` — the `NSObject`-rooted twin keeps `async` for `@objc` bridged completion selectors while pure-Swift protocols leave the witness sync and preserve member inheritance for sibling sync requirements.

## Developer experience
- **Less misleading metadata** — `[UnsupportedSwiftType]` / `[Obsolete(SB0001)]` / `// Unsupported:` no longer ride along on members that are fully bound and callable; Swift `Sendable` conformance is surfaced; closure-parameter skips emit visible tombstones instead of silently omitting the entire method; tombstoned types are pruned from metadata cookie maps so reflection-based tooling no longer sees dangling references.
- **SwiftSyntax interface parser** — Parser schema bumped to v2 with a version handshake between the Swift producer and C# consumer, enabling reliable overload disambiguation across the binding generator; `SwiftInterfaceAccessParser`'s SPI extension conformance path is rewritten as depth-aware helpers (handles attributed conformances like `@available(*, deprecated) Hashable` and trailing where clauses) and expands the `Codable` typealias into `Encodable + Decodable` so SPI-only `Codable` conformances are recognised; the parser captures `EnumCaseDecl.OuterTupleLabel` for `case foo(label: (a:, b:, ...))` shapes so the enum-case wrapper can rebuild the surface call positionally.
- **ObjC-only Apple system frameworks via `<SwiftAppleFrameworkTarget>`** — Consumers can now author one-liner binding csprojs for ObjC-only Apple system frameworks (e.g. `Matter`, `MatterSupport`) using a three-property contract (`SwiftAppleFrameworkTarget` + `SwiftFrameworkType=ObjC` + `IsBindingProject=true`); `Sdk.props` evaluates before the csproj body, so `IsBindingProject` must be user-declared for `Microsoft.iOS.Sdk`'s binding plumbing to gate at the right phase.
- **Error registry** — Per-module error-type registry built as the foundation for typed-throws bridging; error-registry cross-references rebased onto the resolved C# namespace.
